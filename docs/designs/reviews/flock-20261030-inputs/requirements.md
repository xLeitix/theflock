# User requirements for independent review
The task is to create a full design, not implement it. User requested five design subagents, integration, then one separate review agent. Initial visual design should follow Pigeon Tracker.html, supporting desktop but optimized for mobile. Frontend Vue.js/Bootstrap; backend Express; Facebook login, security/encryption/authentication and local testing. Public GitHub source with a GitHub Actions pipeline that tests and deploys after main pushes/merges. Domain theflock.icet-lab.eu. Instant messaging can be skipped. User clarified hosting on a Google Cloud VM and public sightings with privacy controls. Latest correction: forget Atlas, run MongoDB also on the same VM. User selected Gothenburg, Sweden for the pilot region.
